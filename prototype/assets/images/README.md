# Изображения прототипа

Финальная фотография продукта и корпусов пока не готова. Вместо неё HTML/CSS
показывают нейтральные рамки с подписями. Контур корпуса — условный wireframe,
а не изображение реального изделия или брендовый знак.

`k-image-placeholder--missing` обозначает вариант без фотографии. Его имя
остаётся текстом, а радиокнопка доступна для выбора с клавиатуры.

Не добавлять случайные фотографии из интернета, неутверждённые логотипы,
base64-изображения или изображения производителей без отдельного разрешения.
Будущие согласованные фотографии: локальные оптимизированные файлы с размерами,
осмысленным `alt` и сохранённым соотношением сторон. Декоративным изображениям
нужен пустой `alt`; название опции всегда остаётся рядом текстом.
