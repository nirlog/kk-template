# KORSAC PLAY 1440 — baseline specification v0.1

Дата: 2026-09-28

Статус: рабочая спецификация для первого hero-product KORSAC.

## 1. Роль модели

`KORSAC PLAY 1440` — основная модель линейки KORSAC PLAY и главный кандидат для главной страницы, рекламы и первых продуктовых тестов.

Целевой сценарий:

- современные игры в 2560×1440;
- высокие / очень высокие настройки графики;
- хороший запас по CPU для высокочастотных мониторов;
- разумный баланс производительности, шума, температуры и цены;
- без переплаты за компоненты, которые нужны уже для класса 4K.

|---|---|---|

| GPU | GeForce RTX 5070 12 GB GDDR7 | основной GPU-класс для PLAY 1440 |

| OS | без ОС / Windows 11 — отдельно | не включать в железную базовую цену без отдельного решения |

## 3. Почему Ryzen 7 9700X

AMD указывает для Ryzen 7 9700X:

- 8 ядер / 16 потоков;
- Zen 5;
- boost до 5.5 GHz;
- TDP 65 W;
- сокет AM5;
- поддержку B850;
- рекомендацию использовать premium air cooler.

Для KORSAC PLAY 1440 это хороший баланс между игровой производительностью, теплопакетом и позиционированием среднего+ сегмента.

На старте CPU фиксированный. `CPU_OPTIONS` для PLAY 1440 не вводим, чтобы модель не размывалась и не пересекалась с PLAY 1440 PRO.

## 4. Почему RTX 5070 12 GB

NVIDIA указывает для GeForce RTX 5070:

- 12 GB GDDR7;
- Total Graphics Power — 250 W;
- рекомендованную мощность системы — 650 W;
- поддержку PCIe Gen5 power cable / адаптера в зависимости от исполнения платы.

Для KORSAC PLAY 1440 фиксируем RTX 5070 как базовый GPU-класс.

На старте `GPU_OPTIONS` не вводим. Если покупателю нужен RTX 5070 Ti-class, интерфейс должен предлагать `KORSAC PLAY 1440 PRO`, а не превращать младшую модель в старшую через конфигуратор.

## 5. Материнская плата: минимальный стандарт KORSAC

В HL-блоке можно хранить упрощённое значение вроде:

`Материнская плата B850 Wi-Fi`

Но фактическая установленная плата должна удовлетворять минимальному стандарту:

- AMD B850;
- ATX предпочтительно, mATX допустимо только для специально утверждённых корпусов;
- DDR5;
- AMD EXPO;
- минимум 2× M.2 NVMe, желательно 3+;
- минимум один M.2 PCIe 5.0;
- 2.5 GbE;
- Wi-Fi 6E / Wi-Fi 7;
- достаточная VRM для Ryzen 7 9700X без ограничений по power limits;
- BIOS Flashback / аналогичная функция желательна;
- достаточное количество PWM-разъёмов для корпусных вентиляторов.

Точная модель платы фиксируется в заказе и KORSAC SYSTEM ID.

## 6. RAM

### Default

`32 GB DDR5-6000 CL30, 2×16 GB, AMD EXPO`

### Разрешённые варианты

- 32 GB DDR5-6000 — default;
- 64 GB DDR5-6000 — upgrade.

16 GB в PLAY 1440 не предлагаем: это не соответствует middle+ позиционированию модели.

96/128 GB не нужны для игровой модели; такой запрос лучше переводить в CREATE или специальную конфигурацию.

Важно: DDR5-6000 EXPO является профилем разгона памяти относительно официальной JEDEC-спецификации CPU, поэтому KORSAC должен применять только проверенные комплекты и валидировать стабильность итоговой системы стресс-тестами.

## 7. SSD

### SSD1 default

`1 TB NVMe PCIe 4.0 TLC`

### SSD1 options

- 1 TB — default;
- 2 TB;
- 4 TB — только если есть экономически разумный вариант в HL.

### SSD2 default

`Не установлен`

### SSD2 options

- Нет — default;
- 1 TB;
- 2 TB;
- 4 TB.

Для middle+ системы предпочтительно не использовать QLC как основной накопитель без явного обозначения. Базовый стандарт — TLC-class.

После получения реальной разницы цен из HL стоит отдельно решить, не сделать ли 2 TB новым default для PLAY 1440. В v0.1 сохраняем 1 TB, чтобы не менять уже утверждённую продуктовую архитектуру без фактических данных по себестоимости.

## 8. PSU

Базовый стандарт:

`750 W / 80 PLUS Gold / ATX 3.1 / native Gen5 GPU cable`

Почему 750 W:

- NVIDIA для reference RTX 5070 указывает 650 W required system power;
- 750 W даёт разумный запас;
- позволяет держать БП дальше от максимальной нагрузки;
- соответствует middle+ позиционированию;
- не создаёт бессмысленной переплаты за 850–1000 W в системе этого класса.

PSU должен быть из утверждённого списка моделей / OEM-платформ. Одной надписи `750 W Gold` недостаточно для KORSAC.

## 9. Cooling

AMD рекомендует для Ryzen 7 9700X premium air cooler.

Для PLAY 1440 базовым считаем тихое воздушное охлаждение:

- tower 120/140 mm class;
- PWM;
- достаточный thermal headroom для длительной игровой нагрузки;
- отсутствие обязательной AIO в базовой модели.

AIO 240/280 mm можно позже рассматривать как визуальную / акустическую опцию, но она не должна быть обязательной для 9700X.

## 10. Корпуса

Корпус — единственный компонент, где для KORSAC особенно важна точная модель, потому что он формирует внешний вид продукта.

Предлагаемый shortlist для проверки закупочной цены и доступности:

1. **Lian Li LANCOOL 217 Black** — кандидат на основной корпус;
2. **Fractal Design North Charcoal Black** — premium / lifestyle вариант;
3. **be quiet! Pure Base 501 DX Black** — строгий минималистичный вариант;
4. **Montech AIR 903 MAX Black** — более рациональный airflow-вариант.

Критерии допуска корпуса в PLAY 1440:

- mesh / свободный airflow;
- tempered glass либо качественная mesh-панель;
- нормальный фронтальный intake;
- поддержка длинных современных GPU;
- кабель-менеджмент;
- пылевые фильтры;
- минимум USB-A + желателен USB-C на фронтальной панели;
- возможность тихой работы на низких оборотах;
- визуальное соответствие бренду KORSAC.

Фактический default выбираем только после сравнения закупочной цены, стабильности наличия у поставщиков и качества сборки.

## 11. Конфигурируемые свойства товара

Для v0.1 пользователь может менять только:

- `KK_RAM_OPTIONS`;
- `KK_SSD1_OPTIONS`;
- `KK_SSD2_OPTIONS`;
- `KK_CASE_OPTIONS`.

CPU и GPU фиксированы.

Свойства по умолчанию:

- `KK_CPU`;
- `KK_GPU`;
- `KK_MB`;
- `KK_RAM`;
- `KK_SSD1`;
- `KK_SSD2`;
- `KK_CASE`;
- `KK_PSU`;
- `KK_COOLER`.

`*_OPTIONS` не участвуют в расчёте базовой цены товара.

## 12. Расчёт цены

`kk.price-update` рассчитывает стандартную цену базовой конфигурации по default-компонентам из HL-блоков.

Frontend показывает изменение цены по формуле:

```text
FINAL_PRICE = BASE_PRODUCT_PRICE
            + Σ(SELECTED_COMPONENT_PRICE - DEFAULT_COMPONENT_PRICE)
```

Финальная цена всегда повторно рассчитывается на backend перед добавлением в корзину.

Если в pricing engine применяются процентные или фиксированные корректировки, дельта должна рассчитываться через тот же серверный pricing service, а не отдельной независимой формулой JavaScript.

## 13. Что должно попасть в корзину

Одна позиция:

`KORSAC PLAY 1440`

С basket properties / snapshot:

- CPU;
- GPU;
- motherboard;
- RAM;
- SSD1;
- SSD2;
- case;
- PSU;
- cooler;
- итоговая цена конфигурации;
- revision / product code.

Две разные конфигурации одного PRODUCT_ID не должны склеиваться в одну basket position.

## 15. KORSAC quality floor

Даже если HL-блок использует обобщённые названия компонентов, KORSAC должен иметь внутренний approved list.

Запрещено автоматически ставить любой компонент, который формально совпадает по категории.

Для каждой группы нужен минимальный стандарт качества:

- GPU — список допустимых производителей / серий;
- motherboard — VRM / I/O / network floor;
- RAM — approved kits;
- SSD — тип NAND и минимальный performance/reliability floor;
- PSU — только утверждённые модели / платформы;
- cooler — утверждённый thermal/noise floor;
- case — утверждённый список моделей.

Точная установленная модель должна сохраняться в KORSAC SYSTEM ID.

## 16. Проверка перед продажей

Перед публикацией заявлений о FPS и температурах модель должна пройти собственную валидацию KORSAC:

- BIOS update / configuration;
- RAM stability test;
- CPU stress test;
- GPU stress test;
- combined load;
- SSD health / benchmark;
- проверка температуры CPU/GPU/SSD;
- проверка шума и fan curve;
- проверка портов и сети;
- визуальная проверка сборки и cable management.

FPS на сайте публикуется только по результатам собственной тестовой машины той же revision.

## 17. Данные, которых не хватает для финальной цены

Чтобы получить фактическую цену `KORSAC PLAY 1440` через текущую инфраструктуру King-Komp, нужны значения `UF_PRICE` из production HL-блоков для:

- Ryzen 7 9700X;
- GeForce RTX 5070 12 GB;
- B850 Wi-Fi motherboard-class;
- 32 GB DDR5;
- 64 GB DDR5;
- SSD 1 TB;
- SSD 2 TB;
- SSD 4 TB при наличии;
- PSU 750 W Gold / ATX 3.x;
- cooler-class;
- выбранных 3–4 корпусов.

После получения этих значений рассчитываем:

1. базовую себестоимость / базовую цену;
2. дельты опций;
3. целевую розничную цену;
4. gross margin;
5. разрыв до PLAY 1080 и PLAY 1440 PRO.
